# Lab2
Домашнее задание к работе 2
Условие:
Работник зарабатывает х руб. за каждый из 38 часов своей работы. Ему платят в 1,5 раза больше за каждый час сверх 38 часов. Какую сумму он получит, если работает а часов? (а должно быть заведомо больше 38 часов).
1. Алгоритм и блок-схема:
  1.Начало
  2. Обьявление констант:
     Norm_day = 38
  3. Задать исходные данные:
     X - Цена работы за час
     A - кол-во часов работы
  4. Найти сколько часов работы после 38:
       hours_after = A - 38
  5. Посчитать сколько он заработал за 38 часов:
       Pay = X * 38
  6. Посчитать сколько он заработал после 38 часов:
       Pay_after = 1.5*X*hours_after
  7. Найти общую сумму за все часы:
       total_Pay = Pay+Pay_after
  8. Вывести результаты расчетов и подставить значения в текст.
  9. Конец
